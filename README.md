# Corazón humano 3D — Secundaria

Visor 3D interactivo del corazón humano para Ciencias y Biología de secundaria.

*Elaborado por **Alberto Jiménez Ruiz**.*

**Abrir en línea:** https://hoja1304-sudo.github.io/corazon-3d-secundaria/

- Modelo realista con latido: cavidades, tabique, válvulas, cuerdas tendinosas, músculos papilares, grandes vasos, coronarias y pericardio.
- Corte para ver el interior (4 cámaras, frontal, lateral, transversal).
- Modo didáctico con sangre pobre (azul) y rica (rojo) en oxígeno, y flujo animado.
- Botón **Limpia** para ver el corazón sin etiquetas ni textos.
- Botón **Voz**: al tocar una parte o su etiqueta se lee en voz alta (se puede apagar).
- Recorrido de la sangre en 12 pasos y práctica de 10 preguntas.

Funciona en el navegador; necesita conexión a internet para cargar la librería three.js.
